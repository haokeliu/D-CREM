# Third-party notices

This source release does not redistribute third-party datasets, pretrained
model weights, the original MATLAB packages, or publisher-owned paper files.

The `baselines/` directory contains clean Python implementations based on the
published algorithms and publicly described reference implementations of:

- SLAN, introduced in *Multi-label Open Set Recognition* (NeurIPS 2024).
- MUENL-F, introduced in *Multi-label Learning with Emerging New Labels*
  (IEEE TKDE, 2018).

The `crem/` directory reproduces the method described in
*Classifier-induced Reciprocal Points for Multi-label Open-set Recognition*.
